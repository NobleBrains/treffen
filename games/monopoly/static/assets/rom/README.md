### `10_3D_Modelle/`
Die Original-3D-Modelle des Spiels liegen im proprietären **`.hgs`**-Format der 3D-Engine (Venan/Mercury 3D-Engine) vor (inklusive aller 72 Animationsdateien).

### `11_3D_Modelle_OBJ/`
Alle spielrelevanten 3D-Modelle wurden mithilfe des Konverters in standardkonformes **Wavefront `.obj`** (mit Vertices, Normalen, Textur-Koordinaten/UVs und Dreiecks-Flächen) konvertiert:
- **`Gebaeude/`**:
  - `haus.obj`: Das klassische grüne Monopoly-Haus (inkl. Schornstein & Dachüberhang)
  - `hotel.obj`: Das rote Monopoly-Hotel
  - `gefaengnis.obj`: 3D-Gefängniszelle
- **`Spielfiguren/`**:
  - Alle 8 Spielfiguren jeweils in High-Poly (`.obj`) und Low-Poly (`_low.obj`):
    - `zylinder.obj` / `zylinder_low.obj`
    - `schlachtschiff.obj` / `schlachtschiff_low.obj`
    - `rennwagen.obj` / `rennwagen_low.obj`
    - `hund.obj` / `hund_low.obj`
    - `buegeleisen.obj` / `buegeleisen_low.obj`
    - `schuh.obj` / `schuh_low.obj`
    - `fingerhut.obj` / `fingerhut_low.obj`
    - `schubkarre.obj` / `schubkarre_low.obj`
- **`Wuerfel/`**:
  - `wuerfel.obj`: Vollständiges 3D-Würfelmodell

### Konverter-Skript `hgs_to_obj.py`
Das Konverter-Skript liegt direkt im Verzeichnis: [`hgs_to_obj.py`](file:///var/home/lukhicken/AGY/Skribbol/Monopoly/Rom/Assets/hgs_to_obj.py)
- **Einzelne Datei konvertieren**:
  ```bash
  python3 hgs_to_obj.py <eingabe.hgs> <ausgabe.obj>
  ```
- **Alle Modelle im Batch neu generieren**:
  ```bash
  python3 hgs_to_obj.py --batch
  ```
